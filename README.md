AptTil

Distribution repository for approved update packages of Apteekin Tilausehdotus.

Purpose

This repository is used only to publish signed update packages for the Windows Portable version of the application.

It does not contain the application source code, pharmacy data, medicine sales reports, stock reports, Salkku reports, user credentials, or development materials.

Updates

The application may use published GitHub Releases from this repository to:

check whether a newer approved version is available;
download a signed update package after user approval;
verify the update package before installation;
install the update locally and retain rollback capability.

Only published stable Releases are intended for installation through the application.

Data privacy

The application processes uploaded pharmacy reports locally on the user's computer. This repository is not used to receive or store pharmacy report data.
