# AptTil public distribution gateway

This public repository is the anonymous update endpoint for approved AptTil
Windows Portable releases. It is generated by protected workflows in the private
AptUtil monorepo and is not a second development repository.

## What belongs here

- published GitHub Release assets;
- the legacy `update-index.json` while older clients still require it;
- `update-index-v4.json` after the signed v4 migration is approved;
- public protocol schemas, distribution policy, and security guidance.

Application source, signing keys, build inputs, GitHub credentials, pharmacy
reports, medicine sales or stock reports, customer information, and local
configuration do not belong here.

## Update trust

The index selects a release but does not authorize it. AptTil verifies the release
manifest with the trusted public key installed on the pharmacy computer, then
verifies the package hash, byte count, exact ZIP entries, and every file hash
before staging an update. Persistent data and the trust anchor are never release
payload targets.

Candidates are created once, tested by exact package SHA-256, and promoted from
test to stable without rebuilding. Binary packages remain in GitHub Releases so
repository history stays small.

## Privacy

AptTil processes uploaded reports locally. This repository does not receive or
store pharmacy report data.
